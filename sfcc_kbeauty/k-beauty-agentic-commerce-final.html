Executive Summary

제안 개요

본 제안서는 K-Beauty 브랜드가 국내 및 해외 시장에서 본사 직접판매(D2C)와 하위 파트너(SNS 인플루언서, 유튜버, 세일즈 컨설턴트, B2B 셀러 등)를 통한 판매를 하나의 플랫폼 위에서 통합 운영할 수 있도록, Salesforce B2C Commerce, Order Management(Omnichannel Inventory 포함), Experience Cloud/LWC, 그리고 Agentforce 기반의 AI 에이전트를 결합한 구축 방향을 제시합니다.

K-Beauty 산업은 2025~2026년 사이 수출·해외 매출 모두 역대 최고치를 경신하며 성장하고 있으며, 특히 TikTok Shop을 비롯한 소셜 커머스가 발견(Discovery)부터 구매(Checkout)까지 이어지는 핵심 채널로 자리잡았습니다.

동시에 브랜드는 SNS 인플루언서·리셀러·B2B 셀러 등 다층적인 파트너 네트워크를 통해 매출을 확장하고 있어, '본사 주도의 단일 채널 커머스'가 아니라 '다수의 파트너가 다양한 채널에서 판매하고, 본사가 이를 하나의 시스템으로 통합 관리하는' 구조가 요구됩니다.

본사와 파트너 간 상품 공급 관계(B2B/B2B2C), 파트너별 개별 어드민을 통한 판매 현황·정산 조회(Partner Experience), 다채널에서 발생하는 주문의 통합 수집과 배송 처리 방식의 유연한 분기(Order Orchestration), 그리고 해외 진출 시 요구되는 다통화·다언어·현지 세금 대응(Global Commerce)까지 아우르는 통합 아키텍처를 구성합니다.

핵심 제안 요약

본사 스토어프론트

B2C Commerce

Salesforce B2C Commerce로 구축하여 국내외 메인 판매 채널이자 마스터 상품/가격/재고 정보의 허브 역할을 수행합니다.

파트너 플랫폼

B2B Commerce + D2C Commerce

B2B Commerce 기반 사입·발주 기능과 D2C Commerce 기반의 경량 개별 스토어프론트를 제공하여, 별도의 무거운 구축 없이도 빠르게 파트너 채널을 확장할 수 있도록 합니다.

통합 주문 관리

Order Management + Omnichannel Inventory

모든 채널(본사 스토어프론트, 파트너 SNS/소셜커머스, 오프라인 매장·팝업)에서 발생하는 주문은 Order Management로 통합 수집되며, Omnichannel Inventory가 파트너 창고를 포함한 전체 로케이션의 재고를 실시간으로 통합 관리합니다.

파트너 어드민

Experience Cloud + LWC

Experience Cloud와 LWC 커스텀 컴포넌트로 파트너 전용 개별 어드민을 구축하여, 파트너가 상품 주문, 판매 현황, 계약 기반 정산 내역을 직접 조회할 수 있도록 합니다.

AI 기반 자동화

Agentforce

Agentforce 기반의 Shopper Agent, Merchant Agent, Service Agent를 전 채널에 적용하여 상담형 구매 지원, 재고 최적화, 파트너/고객 서비스 자동화를 구현하고, 향후 ChatGPT·Gemini 등 외부 AI 채널과의 연동까지 확장 가능한 구조로 설계합니다.

글로벌 확장

Multi-Site + MuleSoft

B2C Commerce의 다국가 사이트 그룹, 다중 통화(최대 150개 통화) 및 로컬라이제이션 기능과 MuleSoft 기반의 현지 결제·세금·물류 연동을 결합하여, 국가별 신규 사이트 오픈 리드타임을 최소화합니다.

기대 효과

채널 파편화 해소

본사 스토어프론트, 파트너 SNS, 오프라인 매장에서 발생하는 판매 데이터가 단일 오더 뷰(Single Order View)로 통합되어 전사 매출 현황을 실시간으로 파악

파트너 운영 효율화

파트너별 수기 정산 및 이메일/엑셀 기반 소통을 Experience Cloud 포털로 대체하여 정산 리드타임과 문의 대응 공수를 절감

재고 효율화

Omnichannel Inventory 기반의 위치 통합 재고 가시성으로 품절·과잉재고를 동시에 줄이고, 채널 간 재고 이관 유연성 확보

해외 진출 가속화

국가별 로컬라이제이션을 표준 템플릿화하여 신규 시장 진입 리드타임 단축 및 초기 구축비용 절감

AI 기반 매출 확대

Agentforce 기반 에이전트형 쇼핑 경험 도입 기업은 도입하지 않은 기업 대비 매출 성장률이 유의미하게 높게 나타나는 것으로 조사되어, 상담형 구매 지원과 AI 채널 연동을 통한 신규 고객 유입 확대를 기대할 수 있습니다.

실제 사례: COSRX 파트너 크리에이터 네트워크 판매

브랜드 및 제품 개요

COSRX는 성분 중심의 더마 코스메틱 기초 스킨케어 전문 브랜드로, 피부 고민 솔루션형 제품에 집중하여 글로벌 시장에서 성공했습니다. 146개국에 제품을 공급하며, 특히 스네일 뮤신(TikTok 바이럴 1위), BHA 블랙헤드, 센텔라 등 주요 성분을 전면에 내세운 제품들이 크리에이터 네트워크 기반 판매의 핵심이 되었습니다.

성공 요인: 단일 성분 집중 마케팅으로 교육형 콘텐츠 제작이 용이하고, 명확한 피부 고민-솔루션 매칭으로 소비자 선택 장벽을 낮춤. Before/After 비주얼 효과가 명확하여 TikTok/Instagram 숏폼 콘텐츠에 최적화되었으며, 합리적 가격대($15~$30)로 마이크로 인플루언서 시딩 비용이 효율적입니다.

판매 유형 및 방식

1. 본사 직접 판매 (D2C)

  • 공식 웹사이트(cosrx.com) 운영: 유일한 공식 온라인 스토어
  • Apple Pay, Klarna, Google Pay 등 다양한 결제 수단 지원
  • 피부 고민별 제품 큐레이션 및 맞춤형 루틴 빌더 제공

2. 글로벌 파트너 유통망

  • Shop by Country: 146개국 오프라인 매장 네트워크
  • H&B 스토어: 올리브영(한국), Sephora, Ulta(미국) 등
  • 로컬 이커머스: Amazon, YesStyle 등 글로벌 플랫폼

3. 소셜 커머스 (TikTok Shop 중심)

  • TikTok Shop 미국: 뷰티 카테고리 최고 성장 브랜드
  • 다층 크리에이터 네트워크 활용 상시 운영형(always-on) 전략
  • 교육형 콘텐츠(GRWM, 성분 설명, 사용 전후) 중심

4. Affiliate 프로그램

  • COSRX Affiliate Club 운영
  • 마이크로·나노 인플루언서 중심 시딩 전략
  • 지속적인 UGC(User Generated Content) 생성 구조

파트너 크리에이터 네트워크 관리

크리에이터 계층 구조

  • 메가 인플루언서: 대형 캠페인용, 브랜드 인지도 확산
  • 매크로 인플루언서: 카테고리별 전문성, 리뷰 신뢰도 높음
  • 마이크로 인플루언서: 틈새 커뮤니티, 높은 참여율
  • 나노 인플루언서: 상시 운영, 가장 높은 ROI

운영 방식

  • 단발성 유료 광고보다 지속적 제품 시딩 우선
  • 크리에이터 자율 콘텐츠 제작 → 진정성 높은 리뷰
  • 성과 기반 커미션 구조 (Affiliate Link/TikTok Shop 연동)
  • 실시간 판매 데이터 기반 크리에이터 성과 추적

콘텐츠 전략

  • 성분 중심 스토리텔링: 스네일 뮤신, BHA, 센텔라 등
  • 교육형 롱폼 + 짧은 훅(Hook) 쇼츠 조합
  • Before/After 비주얼 중심 → 높은 전환율
  • 피부 타입별 루틴 제안 → 크로스셀 유도

다채널 통합

  • TikTok → Instagram → YouTube → 공식몰 유입 경로 설계
  • 각 플랫폼별 최적화 콘텐츠 형식 적용
  • SNS 프로모션 코드 → 유입 경로 추적 가능

매출 및 성과

TikTok Shop 성과 (미국 시장)

  • 다층 크리에이터 캠페인 후 매출 2배 확대
  • 채널 성과(전환율, 고객 획득 비용) 15% 추가 개선
  • 교육형 콘텐츠의 평균 전환율이 일반 광고 대비 3~5배 높음
  • 마이크로 인플루언서 ROI가 메가 인플루언서 대비 평균 60% 우수

글로벌 매출 구조 (추정)

  • 북미: 전체 매출의 약 40% (최대 시장)
  • 아시아: 약 35% (한국, 일본, 동남아)
  • 유럽·중동: 약 15%
  • 기타 지역: 약 10%

채널별 기여도

  • 소셜 커머스(TikTok Shop 포함): 약 30%
  • 오프라인 리테일(Sephora, 올리브영 등): 약 35%
  • 공식 D2C: 약 20%
  • 기타 이커머스(Amazon 등): 약 15%

해외 진출 전략 및 성과

진출 전략

  • 1단계: 로컬 이커머스 + Affiliate 시딩 → 인지도 확보
  • 2단계: TikTok/Instagram 크리에이터 네트워크 확장 → 바이럴
  • 3단계: 대형 리테일(Sephora, Ulta) 입점 → 오프라인 신뢰도
  • 4단계: 공식 D2C 확장 → 고객 데이터 확보 및 직접 관계 구축

지역별 현지화

  • 미국: 더마 코스메틱 포지셔닝, 성분 투명성 강조
  • 일본: 민감성 피부·저자극 메시지, 상세 성분표 제공
  • 동남아: 트로피컬 환경 대응(유분 밸런스, 워터프루프), 가격 접근성
  • 유럽: 클린 뷰티·비건 인증, GDPR 준수

핵심 성공 요인

  • 단일 SKU 집중 전략: 핵심 제품(Snail Mucin, BHA Blackhead) 우선 확산
  • 성분 중심 교육: 소비자가 '왜 효과적인지' 이해 → 재구매율 상승
  • 크리에이터 자율성 보장: 과도한 스크립트 없이 진정성 유지
  • 빠른 피드백 반영: 크리에이터·고객 의견 기반 제품 개선

시나리오 1: 인플루언서를 통한 SNS 판매 (Referral Code 방식)

방식 개요: Referral Code (인플루언서/SNS 파트너)

개념: 인플루언서가 공유한 링크(?ref=코드)로 유입된 고객의 주문을 코드 기준으로 구분

사용 사례: 유튜브 "건강한 아빠 채널", 인스타그램 인플루언서, 네이버 블로거

실제 사례: 쿠팡 파트너스, 아마존 어필리에이트, 무신사 앰버서더

주요 장점:

  • 간편한 추적: 파트너가 별도 로그인이나 시스템 접근 없이 링크만으로 매출 기여 추적
  • 긴 쿠키 수명: 7일 유지로 고객이 즉시 구매하지 않아도 재방문 시 인식
  • 자동 할인 연동: 프로모션 규칙과 연결하여 코드별 할인 자동 적용 가능
  • 확장성: 수백~수천 명의 마이크로/나노 인플루언서 관리에 적합
1

파트너 코드 발급

Business Manager에서 캠페인으로 인플루언서별 고유 코드 등록 (예: healthydad2026) → Experience Cloud 파트너 포털에서 신청 및 본사 승인 → 판매 가능 제품 및 수수료율 설정

2

유입 시 코드 캡처

고객이 인플루언서 링크 클릭 (예: brand.com?ref=healthydad2026) → B2C Commerce가 URL의 코드를 세션·쿠키에 저장 (7일 유지) → 이탈 후 재방문해도 인식 가능

3

주문 시 기록

고객이 제품 선택 및 결제 완료 → 저장된 Referral Code를 주문 정보(Custom Attribute)에 자동 기록 → (선택) 코드 사용 고객에게 프로모션 규칙 연결하여 자동 할인 제공 가능

4

주문 통합 및 처리

모든 주문이 Salesforce Order Management로 유입 → Referral Code 포함된 주문 데이터 전달 → 재고 확인 (Omnichannel Inventory) → 최적 배송지 결정 (본사 창고) → 배송 실행

5

정산 데이터 전달 및 성과 추적

OMS에서 인플루언서별 매출 집계 (Referral Code 기준) → Experience Cloud 파트너 포털에서 실시간 매출 확인 → 계약된 수수료율에 따라 정산 금액 자동 계산 → 월말 일괄 지급

💡 B2C Commerce 실제 구현 방법 요약

1. Campaign 및 Source Code 설정

  • 메뉴: Business Manager → Merchant Tools → Online Marketing → Campaigns
  • Campaign 생성 (예: influencer_2026)
  • 각 인플루언서에게 고유 Source Code 할당 (예: healthydad2026)
  • URL 형식: https://brand.com?cgid=influencer_2026&src=healthydad2026

2. Custom Attribute 설정 (선택사항)

  • 메뉴: Business Manager → Administration → Site Development → System Object Types
  • Order 객체에 "referralCode" Custom Attribute 추가 (Type: String, Searchable: Yes)
  • 더 세밀한 추적 및 리포팅에 활용

3. Storefront 코드 구현

  • SFCC가 URL의 src 파라미터를 자동으로 session.clickStream.sourceCode에 저장
  • 쿠키에 7일간 저장하여 재방문 시에도 추적
  • Checkout 시 Order Custom Attribute에 기록

4. 주문 추적 및 리포팅

  • Orders 검색: Merchant Tools → Ordering → Orders (Custom Attribute로 필터링 → CSV Export)
  • Campaign Reports: Reports & Dashboards → Site Reports (Source Code 기준 매출 집계)
  • OCAPI 자동화: Order Search API로 Referral Code 기준 주문 조회

5. Experience Cloud 파트너 포털 연동

  • B2C Commerce → OCAPI/Data Export → MuleSoft/Data Cloud → Experience Cloud
  • 파트너별 LWC 대시보드에서 실시간 매출 및 정산 조회

주문 통합 아키텍처

Salesforce Order Management의 역할

모든 채널(온라인몰, SNS, 오프라인, 파트너 채널)에서 발생한 주문이 Salesforce Order Management (SOM)로 실시간 유입됩니다. SOM은 다음을 수행합니다:

  • 주문 정규화: 다양한 형식의 주문 데이터를 표준 포맷으로 변환
  • 재고 확인: Omnichannel Inventory를 통해 모든 창고 및 매장의 실시간 재고 확인
  • 주문 라우팅: 고객 위치, 재고 위치, 배송 비용, 배송 시간을 고려한 최적 배송 경로 결정
  • 분할 배송: 필요 시 여러 창고에서 하나의 주문을 나누어 배송
  • 주문 추적: 통합된 주문 상태 관리 및 고객/파트너에게 실시간 업데이트

정산 자동화 프로세스

1

실시간 매출 추적

파트너의 리퍼럴 코드/링크를 통한 모든 주문이 자동으로 해당 파트너에게 귀속 → Experience Cloud 포털에서 실시간 매출 확인 가능

2

반품/취소 반영

주문 취소, 반품 발생 시 자동으로 파트너 매출에서 차감 → 정산 금액 재계산

3

수수료 계산

계약된 수수료율 및 인센티브 조건 자동 적용 → Salesforce Revenue Cloud에서 정산 금액 자동 계산

4

정산서 발행

정산 주기(월말, 격주 등)에 자동으로 정산서 생성 → 파트너 포털에서 다운로드 가능 → 이메일 자동 발송

5

지급 실행

정산서 승인 후 자동 계좌 이체 (또는 수동 승인) → 지급 완료 알림 → 다음 주기 매출 집계 시작

전체 프로세스 요약

통합 비즈니스 플로우

  1. 파트너 온보딩: Experience Cloud 포털에서 신청 및 승인
  2. 제품 홍보: 파트너가 자신의 채널(SNS, 오프라인 등)에서 제품 홍보
  3. 고객 구매: 고객이 본사 공식몰 또는 SNS 플랫폼에서 구매
  4. 주문 통합: 모든 채널의 주문이 Order Management로 실시간 수집
  5. 재고 확인: Omnichannel Inventory에서 최적 출고 위치 결정
  6. 배송 실행: 자동 라우팅 및 배송사 연동으로 배송 시작
  7. 고객 지원: Agentforce가 24/7 자동 응대 (배송 추적, 반품 등)
  8. 정산 처리: 주기적으로 파트너 수수료 자동 계산 및 지급
  9. 성과 분석: 파트너 및 채널별 매출, 전환율, ROI 대시보드 제공
